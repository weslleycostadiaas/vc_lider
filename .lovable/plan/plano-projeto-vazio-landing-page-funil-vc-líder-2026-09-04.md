# Plano: Projeto vazio — Landing Page Funil VC Líder

## Objetivo
Preparar o projeto como uma base vazia e identificada para a futura Landing Page do **Funil VC Líder**, sem desenvolver páginas, seções ou funcionalidades neste momento.

## O que será feito
1. **Identidade do projeto**
   - Atualizar o título e a descrição padrão em `src/routes/__root.tsx` para "Funil VC Líder".
   - Atualizar o `name` em `package.json` para refletir o nome do projeto.

2. **Manter a página inicial vazia**
   - Preservar `src/routes/index.tsx` como placeholder, sem substituir por conteúdo de landing page.
   - Não criar rotas adicionais, componentes, seções, imagens ou lógica de negócio.

3. **Verificação mínima**
   - Garantir que o projeto continue compilando corretamente após os ajustes de identidade.

## O que NÃO será feito
- Nenhum design, copy, imagem, formulário, animação ou seção de landing page será implementado.
- Nenhuma integração de backend, banco de dados, analytics ou ferramenta de marketing será adicionada.

## Resultado esperado
Um projeto TanStack Start vazio, com metadados apontando para o Funil VC Líder, pronto para receber o desenvolvimento da landing page em um próximo passo.
